3 仓库库存调拨  
两个仓库的初始库存均为 0—100 件，调拨数量为 1—100 件。不考虑仓库容量限制，调拨后的库存可以超过 100 件。  
（1）定义一个函数，实现从一个仓库向另一个仓库调拨指定数量的货物。源仓库库存足够时，扣除相应数量，并向目标仓库增加同样数量；源仓库库存不足时，不进行调拨，两个仓库的库存均保持调用前的值。函数应使其调用者能够获知调拨是否成功，并且函数运行结束后仍能保留调拨之后两个仓库的库存情况。  
（2）程序运行时，主函数从键盘读取两个仓库的初始库存及调拨数量，调用自定义函数，在主函数中输出调拨是否成功，以及两个仓库的最终库存。  
（3）要求不使用全局变量，程序中须有函数声明语句。调拨函数不直接进行输入或输出。  
主要知识点：函数参数引用传递、函数返回值、函数声明。

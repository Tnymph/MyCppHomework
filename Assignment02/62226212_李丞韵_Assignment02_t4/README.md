4 按结束条件读取字符并逆序输出  
使用 cin.get 从键盘逐个读取字符，遇到以下任一情况即停止：已读入 20 个字符，或最近连续读入的 3 个字符依次为 e、n、d。随后将实际读入的全部字符逆序输出。  
输入限定为英文、数字、标点、空格和换行等单字节字符；空格与换行也要读入并计入 20 个字符。触发停止的 e、n、d 属于已读入内容，也参与逆序输出。  
主要知识点：cin.get、逻辑表达式。  

思考题  
短路求值与条件顺序  
第 4 题中，字符数组 s 的容量为 20，整型变量 n 表示已经读入的字符数，且 0≤n≤20。已读入的字符依次保存在 s[0]至 s[n-1]中；n 为 0 时尚未读入字符。为判断最近读入的三个字符是否依次为 e、n、d，某同学写出了以下三种表达式。  
甲 (n >= 3) && (s[n-3] == 'e') && (s[n-2] == 'n') && (s[n-1] == 'd')  
乙 (n >= 3) & (s[n-3] == 'e') & (s[n-2] == 'n') & (s[n-1] == 'd')  
丙 (s[n-3] == 'e') && (s[n-2] == 'n') && (s[n-1] == 'd') && (n >= 3)  
（1）当 n 为 2，且已经读入的两个字符依次为 e、n 时，三种表达式分别会怎样求值？哪些表达式能安全得出判断结果，哪些会访问数组范围以外的位置？指出相应的下标，并说明原因。无需通过运行程序验证。  
（2）当 n 为 3，且已经读入的三个字符依次为 e、n、d 时，三种表达式的判断结果是否一致？能否据此认为三种写法可以互换？结合第（1）问，说明运算符的选择和条件的排列为什么会影响程序的正确性。

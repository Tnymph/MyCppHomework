4 字符串的输入输出与复制  
（1）从键盘输入姓名拼音与学号，姓氏和名字间用 1 个空格，姓名与学号间用 1 个英文逗号，例如“Zhang San,20260001”。   
整行最多 79 个字符，不计换行。使用 cin.getline 将整行保存到字符数组 aa 中并输出。  
（2）使用 strcpy_s 将 aa 中的字符串复制到字符数组 bb，并输出 bb。按课堂 Visual Studio 环境正确包含头文件。  
（3）不使用字符串处理函数，逐个字符将 aa 中的字符串复制到字符数组 cc，再整体输出cc。

4 用级数递推计算自然对数  
当 x>0.5 时，自然对数可按下列级数计算：  
ln x = t + t²/2 + t³/3 + ⋯  
其中 t = (x−1)/x  
从键盘输入实数 x，先判断 x>0.5 是否成立。不满足时输出提示并结束本次计算；满足时用递推法求近似值，不得使用幂函数或对数函数代替计算，要求恰当使用 break。  
每次生成并累加一项后，若该项的绝对值小于 10⁻⁶，则停止并输出累加结果。最多累加 10000 项；达到上限仍未满足上述停止条件时，输出明确提示，并输出当前累加结果。  
主要知识点：递推、break。  

思考题（2）  
级数的停止条件与计算误差  
第 4 题中，第 k 项为 aₖ=tᵏ/k，前 n 项之和记为 Sₙ。程序在累加某一项后，若该项的绝对值小于 10⁻⁶，就停止累加。某同学认为：“只要按这个条件停止，就一定有|ln(x)−Sₙ|<10⁻⁶。”本题只讨论停止累加造成的截断误差，暂不考虑浮点运算的舍入误差。  
（1）当 x=100 时，t=0.99。累加到第 721 项时，该项约为 9.8864×10⁻⁷，首次满足停止条件。请估算接下来的第 722 项和第 723 项，并据此判断上述结论是否成立，说明理由。无需计算全部未累加项，也不要求推导一般余项公式。  
（2）本题只允许 x>0.5。当 x 从右侧接近 0.5，或 x 较大时，为什么可能需要很多项才能满足停止条件？结合 t 与各项绝对值的变化说明。如果累加 10000 项后仍未满足条件，能否据此断定级数发散？

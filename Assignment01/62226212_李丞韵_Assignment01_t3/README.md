3 判断四个点能否构成矩形  
通过键盘输入任意 4 个点的二维坐标，判断它们能否作为一个矩形的 4 个顶点。
顶点输入顺序任意，矩形相对于坐标轴可以旋转任意角度。  
若能构成矩形，输出判断结果及面积；否则输出不能构成矩形。  
正方形属于矩形；含重复点或面积为 0 的退化情形不构成矩形。  
涉及计算结果的相等判断时，统一约定：两个比较量的绝对差不超过 0.000001 时，按相等处理。  
主要知识点：逻辑运算、关系运算、条件组合、算法设计。

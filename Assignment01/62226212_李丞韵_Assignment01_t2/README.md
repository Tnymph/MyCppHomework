2 按给定规则计算累进税额  
通过键盘输入一个非负的年收入金额，按照下列假设规则计算并输出应缴税额。各税率只作用  
于收入落在对应区间内的那一部分。  
年收入中的相应部分 税率  
不超过 60000 元的部分 0%  
超过 60000 元且不超过 96000 元的部分 3%  
超过 96000 元且不超过 204000 元的部分 10%  
超过 204000 元且不超过 360000 元的部分 20%  
超过 360000 元的部分 25%  
例如年收入为 400000 元时，应缴税额为：  
(96000−60000)×0.03 + (204000−96000)×0.1 + (360000−204000)×0.2 + (400000−360000)×0.25 = 53080 元。  
主要知识点：多分支判断、分段计算。
